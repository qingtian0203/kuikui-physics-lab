# 葵葵的物理通关 · 电与热（双优融合旗舰版）

专为九年级全一册物理「电功、电功率与焦耳定律」定制的错题靶向通关练习网站。

## 核心亮点
- **温润纸感编辑风 UI**：亚麻暖白基底、双专题语义色隔离、全站定制双色线性矢量图标、沉浸式专注单题流。
- **38 道四阶微颗粒闯关题**：涵盖基础热身 → 拆解原题 → 拔高挑战 → 真题毕业考。
- **全品类标准物理 SVG 图表**：动态发光五拓扑电路图、比例缩放分段用电时间轴、家用电能表末位红框小数位表盘、参数化 $P_{\text{总}}\text{-}t$ 阶梯坐标图。
- **防假性掌握闭环**：一步一解锁分步计算（含 1 次纠错重试与靶向错因拦截）、二级渐进不剧透锦囊、错题连续答对 2 次销号机制、多模态无限随机变式出题器与动态电路实验室。
